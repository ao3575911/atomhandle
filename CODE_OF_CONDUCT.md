# Code of Conduct

This project adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Report unacceptable behavior to the maintainers listed in [.github/CODEOWNERS](.github/CODEOWNERS), or privately via [GitHub Security Advisories](https://github.com/ao3575911/atomhandle/security/advisories/new). Do not open a public issue for a report about a person.
